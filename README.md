This repository contains all code relevant to the data handling and analysis
associated with my final MSc Dissertation.

All data obtained from Audiomoth recordings and BirdNET Analysis are stored in
'audiomoth_data', whilst data from traditional point count surveys are stored in
'birdsurvey_data'. 

Code, statistics, plots, and summary data relevant to the dissertation thesis
are all located within 'phase1_analysis' Additional code, relevant to the
comparison of PAM approaches to traditional survey approaches (which I did not
present in my dissertation) is located in the 'phase2_analysis' folder, but is
currently incomplete.
